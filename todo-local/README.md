# งานของฉัน — To‑Do List ส่วนตัว (local‑first)

เว็บแอปจัดการงานสำหรับคนเดียว ภาษาไทย ธีมสว่าง/มืด ข้อมูลอยู่ในเครื่องคุณเท่านั้น
ไม่มีเซิร์ฟเวอร์รับข้อมูล **ไม่มีระบบล็อกอินหรือรหัสผ่าน** และไม่ซิงก์ข้ามอุปกรณ์

## เริ่มใช้งาน
**แนะนำ (ออฟไลน์ + ติดตั้งได้):** ต้องมี Python 3
```
python3 serve.py        # แล้วเปิด http://localhost:8080
```
เซิร์ฟเวอร์ผูกกับ 127.0.0.1 เท่านั้น จากนั้นใช้เมนูเบราว์เซอร์ → "ติดตั้งแอป / เพิ่มลงหน้าจอหลัก"
(ออนไลน์ผ่าน HTTPS ก็ทำงานเช่นกัน)

**ทางลัด:** ดับเบิลคลิก `index.html` ได้ แต่ file:// ติดตั้งเป็นแอปและใช้ออฟไลน์เต็มรูปแบบไม่ได้

## ข้อมูลเก็บที่ไหน / ข้อจำกัด
- เก็บใน `localStorage` ของเบราว์เซอร์ (คีย์ `todo.v1`) ธีมเก็บที่ `todo.theme`
- ล้างข้อมูลเว็บไซต์ ใช้โหมดส่วนตัว หรือเปลี่ยนเบราว์เซอร์/โปรไฟล์ → ข้อมูลหาย/มองไม่เห็น
- `file://` กับ `http://localhost:8080` (และพอร์ตอื่น) เป็นคนละพื้นที่เก็บ ข้อมูลไม่ข้ามกัน → ส่งออกแล้วนำเข้า
- ใครใช้เบราว์เซอร์โปรไฟล์เดียวกันก็เห็นข้อมูลได้ (ไม่มีการเข้ารหัส/รหัสผ่าน)
- พื้นที่ localStorage ราว 5 MB เพียงพอสำหรับงานหลายพันรายการ

## การแจ้งเตือน
- ตั้งวันที่ + เวลาในงาน แล้วกดปุ่ม 🔔 เพื่ออนุญาตการแจ้งเตือน
- **ทำงานเมื่อเปิดแอป/แท็บค้างไว้เท่านั้น** (ตรวจทุก 15 วินาที) ไม่มี push จากเซิร์ฟเวอร์
- ถ้าไม่อนุญาต จะแสดงข้อความเตือนในหน้าแอปแทน
- งานที่เลยเวลานานกว่า 24 ชม. ขณะปิดแอป จะไม่เด้งเตือนย้อนหลัง (ดูได้ที่ตัวกรอง "เลยกำหนด")

## งานซ้ำ
เมื่อติ๊กงานที่ทำซ้ำ (ทุกวัน/สัปดาห์/เดือน) ว่าเสร็จ ระบบสร้างงานรอบถัดไปให้อัตโนมัติ
(รายเดือนวันที่ 31 จะเลื่อนไปวันสุดท้ายของเดือนที่สั้นกว่า)

## สำรองและกู้คืน
1. กดปุ่ม **?** → **ส่งออกไฟล์สำรอง** ได้ไฟล์ `todo-backup-วันที่.json` (ควรทำเป็นประจำ)
2. กู้คืน: **?** → **นำเข้าไฟล์สำรอง** → ยืนยัน (ข้อมูลเดิมถูก **แทนที่ทั้งหมด**)
3. ก่อนแทนที่ ระบบเก็บสำเนาข้อมูลเดิมไว้ที่ `localStorage` คีย์ `todo.v1.prev` 1 ชุด
   (กู้ด้วยตนเองผ่าน DevTools → Application → Local Storage)
4. หากข้อมูลเสียหายอ่านไม่ได้ จะเก็บสำเนาดิบไว้ที่คีย์ `todo.v1.corrupt`

## ความเป็นส่วนตัว
แอปมี Content‑Security‑Policy `connect-src 'none'` จึงไม่สามารถส่งข้อมูลออกเครือข่ายได้ ไม่มีสคริปต์หรือฟอนต์ภายนอก

## โครงสร้างไฟล์
```
index.html            หน้าหลัก + กล่องโต้ตอบ
css/style.css         ธีมสว่าง/มืด และเลย์เอาต์ responsive
js/theme.js           ตั้งธีมก่อนวาดหน้า (กันกะพริบ)
js/app.js             ตรรกะทั้งหมด: งาน ตัวกรอง แจ้งเตือน สำรองข้อมูล
sw.js                 Service Worker (ออฟไลน์)
manifest.webmanifest  ข้อมูลติดตั้งเป็นเว็บแอป
icons/icon.svg        ไอคอน
serve.py              เซิร์ฟเวอร์ในเครื่อง (127.0.0.1:8080)
```
หลังแก้ไฟล์ ให้เปลี่ยนเลขเวอร์ชัน `C` ใน `sw.js` (เช่น `todo-local-v2`) เพื่อให้แคชอัปเดต
